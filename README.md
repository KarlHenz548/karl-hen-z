# Karl Henz — Developer Portfolio

A personal portfolio website showcasing my projects, technical skills, and journey as a full-stack developer. Built with Next.js, TypeScript, and Tailwind CSS, featuring a warm visual theme and responsive layouts.

## Live Demo

**Website:** [karl-hen-z.vercel.app](https://karl-hen-z.vercel.app/)

## Features

- **Hero Section** — Introduction and developer-focused presentation.
- **About Section** — Background and development interests.
- **Skills Section** — Technologies and tools I work with.
- **Projects Showcase** — Selected projects with descriptions, previews, live demos, and source code links where available.
- **Contact Section** — Ways to connect with me.
- **Responsive Design** — Layouts designed for desktop and mobile devices.
- **Custom Visual Design** — Warm colors, soft neumorphic elements, and consistent styling.

## Tech Stack

- [Next.js](https://nextjs.org/) — React framework with the App Router.
- [React](https://react.dev/) — UI library.
- [TypeScript](https://www.typescriptlang.org/) — Type-safe JavaScript.
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first styling.
- [Lucide React](https://lucide.dev/) — General-purpose interface icons.
- [Simple Icons](https://simpleicons.org/) — Brand and technology icons.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) compatible with the project's dependencies.
- npm, which is included with Node.js.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KarlHenz548/karl-hen-z.git
   ```

2. Navigate to the project directory:

   ```bash
   cd karl-hen-z
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts
